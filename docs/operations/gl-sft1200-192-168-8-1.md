# GL-SFT1200（192.168.8.1）运维操作时间线

设备档案（只读探查所得）：GL.iNet GL-SFT1200（Opal），固件 `4.8.3`，底层 OpenWrt 18.06（`siflower/sf19a28-fullmask`，kernel `4.14.90`），CPU MIPS interAptiv（带 FPU，系统为 hard-float musl `1.1.20`），内存 118MB，overlay 约 87MB。SSH 只提供 `ssh-rsa` 主机密钥，需 `-o HostKeyAlgorithms=+ssh-rsa`。LuCI 在 `:8080/cgi-bin/luci`。登录凭据未写入本仓库。

## 2026-10-23 15:07 CST - 安装 Passwall 26.10.22（最新版）

- 操作人：`Claude`（用户要求安装最新版 Passwall）
- 影响：
  - 新增软件包，**未启用** Passwall（`passwall.@global[0].enabled=0`），未改网络 / 防火墙 / DNS 配置，透明代理未接管流量。

  - C 小工具取 Passwall build feed `packages-21.02/mipsel_24kc`（musl 1.1.x 同代 ABI），哈希与 feed `Packages` 索引一致。
  - feed 里的 `xray-core` / `geoview` 是动态链接 soft-float（解释器 `/lib/ld-musl-mipsel-sf.so.1`），在本机 hard-float musl 上**段错误**；改用上游静态二进制（Xray `Xray-linux-mips32le.zip` 里的 hard-float `xray`，SHA256 与官方 `.dgst` 一致；geoview `geoview-linux-mipsle`）。
  - `lyaml` 无可用包，用 `--force-depends` 跳过；Passwall 只在 Clash 订阅转换里 `pcall(require, "lyaml")`，缺失不影响主功能。
- 备份：`/root/backup-20261023/`（`config/` 全量 `/etc/config`、`opkg.conf`、`installed.txt` 安装前包列表）
- 变更清单：
  - GL 官方源：`coreutils-base64` `coreutils-nohup` `luci-compat` `kmod-ipt-tproxy` `iptables-mod-tproxy` `kmod-ipt-iprange` `iptables-mod-iprange`
  - Passwall feed（21.02）：`chinadns-ng` 2025.08.09、`dns2socks` 2.1、`ipt2socks` 1.1.4、`microsocks` 1.0.5、`tcping` 0.3、`v2ray-geoip` 202610190920、`v2ray-geosite` 202610202206
  - GitHub release：`luci-app-passwall` 26.10.22、`luci-i18n-passwall-zh-cn` 26.10.22
  - 手工放置（不归 opkg 管）：`/usr/bin/xray`（Xray 26.10.21 静态）、`/usr/bin/geoview`（0.2.8 静态）
  - 软链 `/lib/ld-musl-mipsel-sf.so.1 -> libc.so`：让 feed 里的 soft-float 小工具能找到解释器（它们不经 libc 传浮点参数，实测均可运行）
  - `/etc/opkg.conf` 追加 `arch all 1` / `arch noarch 1` / `arch mips_siflower 10` / `arch mipsel_24kc 20`
- 踩坑：
  - `opkg --add-arch X` 会**整体替换**架构列表；`opkg.conf` 原本没有 `arch` 行（用内置默认），只加一行 `mipsel_24kc` 也会覆盖默认。架构列表不全时，opkg 写状态库会静默丢掉"架构无效"的已装包条目（文件仍在）。必须四个架构写全。
  - 不要往 `/tmp` 一次性传大文件，tmpfs 吃的是那 118MB 内存。
- 回滚方式：
  - `opkg remove luci-i18n-passwall-zh-cn luci-app-passwall chinadns-ng dns2socks ipt2socks microsocks tcping v2ray-geoip v2ray-geosite`
  - `rm /usr/bin/xray /usr/bin/geoview /lib/ld-musl-mipsel-sf.so.1 /lib/upgrade/keep.d/xray-core`
  - `cp /root/backup-20261023/opkg.conf /etc/opkg.conf`
  - GL 源依赖按需 `opkg remove`（对照 `/root/backup-20261023/installed.txt`）
