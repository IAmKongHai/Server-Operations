TOVO.SH · SEEDANCE 2.0

Seedance 视频生成接入手册

本服务提供字节跳动 Seedance 2.0 视频生成接口。接口格式与火山方舟官方 API 一致：把官方示例里的地址换成 https://tovo.sh、密钥换成你的令牌，就可以直接调用。

接入信息

接口地址
https://tovo.sh
认证方式
请求头 Authorization: Bearer sk-你的令牌
控制台
浏览器打开 https://tovo.sh，用我们提供的账号登录，可以查看余额、消费明细，也可以在「API 密钥」页面新建或删除令牌
接口格式
火山方舟视频生成原生格式（创建任务 + 查询任务）
请保管好令牌。令牌等同于账户余额的支付凭证，不要写进前端代码或公开仓库。怀疑泄露时，在控制台「API 密钥」页面删除旧令牌、新建一个即可。首次登录后请修改初始密码。

模型与价格

按生成视频实际消耗的 token 计费，价格与火山方舟官方刊例价一致。

三步跑通

先用最便宜的规格（mini、480p、4 秒）确认链路是通的。以下命令在 macOS / Linux 终端直接运行，Windows 可用 Git Bash 或 WSL。

第 1 步　提交任务

bash
export TOVO_KEY="sk-你的令牌"

curl -s https://tovo.sh/api/v3/contents/generations/tasks \
  -H "Authorization: Bearer $TOVO_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "doubao-seedance-2-0-mini-260615",
    "content": [
      { "type": "text", "text": "一只橘猫在窗台上伸懒腰，阳光洒进来，镜头缓慢推近" }
    ],
    "resolution": "480p",
    "ratio": "16:9",
    "duration": 4,
    "generate_audio": false,
    "watermark": false
  }'

成功会立即返回任务 ID：

返回
{"id":"task_wqZPE7wb6pRMq14fEzpfORzNcW1yKeeu"}

第 2 步　查询进度

视频生成需要一到几分钟（实测 480p 4 秒约 1.5 分钟）。每 10 秒左右查询一次，直到 status 变成 succeeded 或 failed。

bash
TASK_ID="task_wqZPE7wb6pRMq14fEzpfORzNcW1yKeeu"   # 换成上一步返回的 id

curl -s https://tovo.sh/api/v3/contents/generations/tasks/$TASK_ID \
  -H "Authorization: Bearer $TOVO_KEY"

完成时的返回（节选）：

返回
{
  "id": "task_wqZPE7wb6pRMq14fEzpfORzNcW1yKeeu",
  "model": "doubao-seedance-2-0-mini-260615",
  "status": "succeeded",
  "content": { "video_url": "https://ark-acg-cn-beijing.tos-cn-beijing.volces.com/...mp4?..." },
  "resolution": "480p",
  "ratio": "16:9",
  "duration": 4,
  "framespersecond": 24,
  "usage": { "completion_tokens": 40594, "total_tokens": 40594 }
}

第 3 步　下载视频

两种方式任选其一：

方式 A：直接下载 video_url（不经过我们的服务器，速度最快）
curl -L -o output.mp4 "这里粘贴 content.video_url 的完整地址"
方式 B：通过 tovo.sh 代理下载（只需要任务 ID 和令牌）
curl -L -o output.mp4 https://tovo.sh/v1/videos/$TASK_ID/content \
  -H "Authorization: Bearer $TOVO_KEY"
视频地址只保留 24 小时。两种方式都依赖同一个临时地址，过期后视频无法再下载。请在任务完成后尽快下载并保存到自己的存储。

Python 完整示例

提交、轮询、下载一次完成。需要 pip install requests。

seedance_demo.py
import os
import time
import requests

BASE_URL = "https://tovo.sh"
API_KEY = os.environ["TOVO_KEY"]          # export TOVO_KEY="sk-你的令牌"
HEADERS = {"Authorization": f"Bearer {API_KEY}"}


def submit_task():
    """提交视频生成任务，返回任务 ID"""
    payload = {
        "model": "doubao-seedance-2-0-mini-260615",
        "content": [{"type": "text", "text": "海浪拍打礁石，黄昏，航拍视角缓慢后退"}],
        "resolution": "480p",
        "ratio": "16:9",
        "duration": 4,
        "generate_audio": False,
    }
    resp = requests.post(f"{BASE_URL}/api/v3/contents/generations/tasks",
                         headers=HEADERS, json=payload, timeout=60)
    resp.raise_for_status()
    return resp.json()["id"]


def wait_for_task(task_id, interval_seconds=10, max_wait_seconds=1800):
    """轮询任务直到结束，返回最后一次查询结果"""
    deadline = time.time() + max_wait_seconds
    while time.time() < deadline:
        resp = requests.get(f"{BASE_URL}/api/v3/contents/generations/tasks/{task_id}",
                            headers=HEADERS, timeout=30)
        resp.raise_for_status()
        task = resp.json()
        print("status:", task.get("status"))
        if task.get("status") in ("succeeded", "failed", "expired", "cancelled"):
            return task
        time.sleep(interval_seconds)
    raise TimeoutError(f"task {task_id} not finished in time")


def download_video(task_id, output_path):
    """经 tovo.sh 代理下载视频（24 小时内有效）"""
    with requests.get(f"{BASE_URL}/v1/videos/{task_id}/content",
                      headers=HEADERS, stream=True, timeout=300) as resp:
        resp.raise_for_status()
        with open(output_path, "wb") as output_file:
            for chunk in resp.iter_content(chunk_size=1 << 20):
                output_file.write(chunk)


if __name__ == "__main__":
    task_id = submit_task()
    print("task id:", task_id)
    task = wait_for_task(task_id)
    if task["status"] == "succeeded":
        download_video(task_id, "output.mp4")
        print("saved output.mp4, tokens:", task["usage"]["completion_tokens"])
    else:
        print("failed:", task.get("error"))

图生视频与参考素材

在 content 数组里加入图片、视频或音频即可。素材可以是公网可访问的 URL；图片和音频也可以用 Base64（如 data:image/png;base64,...）。以下三种用法互斥，一次请求只能选一种。

首帧生成

视频从这张图开始。1 张图，role 填 first_frame（也可以不填）。

请求体
{
  "model": "doubao-seedance-2-0-fast-260128",
  "content": [
    { "type": "text", "text": "女孩转身微笑，头发被风吹起" },
    { "type": "image_url", "image_url": { "url": "https://example.com/first.png" }, "role": "first_frame" }
  ],
  "resolution": "720p",
  "duration": 5
}

首尾帧生成

指定开头和结尾两张图，模型生成中间的过渡。2 张图，role 必填。

请求体
{
  "model": "doubao-seedance-2-0-fast-260128",
  "content": [
    { "type": "text", "text": "花苞缓慢绽放" },
    { "type": "image_url", "image_url": { "url": "https://example.com/start.png" }, "role": "first_frame" },
    { "type": "image_url", "image_url": { "url": "https://example.com/end.png" },   "role": "last_frame" }
  ],
  "resolution": "720p",
  "duration": 5
}

多模态参考

最多 9 张参考图、3 段参考视频、3 段参考音频，在提示词里用「图片1」「视频1」按顺序引用。每个素材的 role 必填。至少要有一张图或一段视频，不能只给音频。带参考视频时按上表「带参考视频」单价计费，参考视频的时长也计入 token。

请求体
{
  "model": "doubao-seedance-2-0-mini-260615",
  "content": [
    { "type": "text", "text": "图片1中的小狗按照视频1的运镜在草地上奔跑" },
    { "type": "image_url", "image_url": { "url": "https://example.com/dog.png" },     "role": "reference_image" },
    { "type": "video_url", "video_url": { "url": "https://example.com/camera.mp4" }, "role": "reference_video" }
  ],
  "resolution": "480p",
  "ratio": "16:9",
  "duration": 5
}
素材要求
图片jpeg / png / webp / bmp / tiff / gif / heic；单张小于 30 MB；宽高比 0.4–2.5；边长 300–6000 px
参考视频mp4 / mov（H.264 或 H.265）；每段 2–15 秒，最多 3 段，总长不超过 15 秒；单个不超过 200 MB；帧率 24–60；只支持 URL
参考音频wav / mp3；每段 2–15 秒，最多 3 段，总长不超过 15 秒；单段不超过 15 MB
整个请求不超过 64 MB（Base64 图片会让请求体变大，素材多时优先用 URL）

参数说明

参数说明
model必填，见「模型与价格」
content必填，数组；文本 {"type":"text","text":"..."} 加可选素材。中文提示词建议 500 字以内
resolution480p 或 720p，默认 720p。fast / mini 不支持 1080p 和 4k，传了会被拒绝
ratio16:9、4:3、1:1、3:4、9:16、21:9、adaptive（按素材自动选择，默认值）
duration视频秒数，4–15 的整数；-1 表示由模型决定长度（此时按最长 15 秒预扣，完成后按实际退差）
generate_audio是否同时生成声音，默认 true；不需要声音时传 false
watermark是否加「AI 生成」水印，默认 false
return_last_frame传 true 时，结果里额外返回尾帧图片 content.last_frame_url，可用于续拍下一段

任务状态与结果

status含义处理
queued排队中继续查询
running生成中继续查询
succeeded完成读取 content.video_url，24 小时内下载
failed失败看 error.code / error.message；失败任务不收费，预扣金额自动退回
expired超时未完成不收费，可重新提交

返回的 id 以 task_ 开头，是本平台的任务号，查询和下载都用它。任务记录也可以在控制台「任务日志」里查看。

计费与余额

  • 提交时预扣：按请求的分辨率和时长估算 token，先从余额里扣掉这部分。余额不足时，提交会直接返回错误，不会产生任务。
  • 完成后结算：按实际返回的 usage.completion_tokens 计价，多退少补。
  • 失败不收费：任务失败或超时，预扣金额全部退回。
  • 查看明细：登录控制台，「钱包」看余额，「使用日志」看每次扣费。
  • 充值：联系我们的商务人员。

限制与常见问题

不支持的功能

  • callback_url（任务完成回调）：传了会被拒绝，请改用轮询查询。
  • 取消任务、列出全部任务：暂不提供，需要时请在自己的系统里记录任务 ID。
  • 1080p、4k：fast 和 mini 两个模型本身不支持。
  • 素材 ID（asset://...）：请改用公网 URL 或 Base64。

常见错误

现象原因与处理
HTTP 401令牌缺失、写错或已被删除。确认请求头是 Authorization: Bearer sk-...
提示余额不足 / 额度不足余额不够本次预扣，联系商务充值
提示分辨率不支持fast / mini 只支持 480p、720p
HTTP 429 或提示请求过多同时进行的任务太多，稍等几秒后重试，并适当降低并发
任务 failed，提示内容审核提示词或素材未通过审核。Seedance 2.0 不接受包含真人人脸的参考图片或视频
素材相关报错素材 URL 必须能从公网直接下载（不能需要登录或签名已过期），并符合上表的格式和尺寸要求
下载视频 403 / 404超过 24 小时，视频地址已失效，需要重新生成
更多提示词写法和素材用法，可以参考火山方舟官方文档《Doubao Seedance 2.0 系列教程》和《创建视频生成任务》。请求格式与本服务一致，调用时把地址换成 https://tovo.sh 即可。
